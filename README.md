## Sobre o projeto

Este portfólio reúne minha experiência e meus estudos em **infraestrutura, monitoramento, observabilidade, cloud, suporte técnico, dados e desenvolvimento**.

A interface combina uma estética **minimalista dark** com referências sutis ao universo de **Half-Life**, mantendo navegação clara, boa leitura e adaptação para computadores e celulares.

## Principais recursos

- Navegação interativa por seções
- Layout responsivo e otimizado para dispositivos móveis
- Projetos adicionais sincronizados automaticamente com o GitHub
- Cartões com tecnologias e cores oficiais das ferramentas
- Currículo disponível para download
- Animações e efeitos visuais sutis
- Links diretos para GitHub, LinkedIn e projetos publicados

## Executando localmente

```bash
git clone https://github.com/Dorfonaltz/rodolfo-portfolio.git
cd rodolfo-portfolio
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no navegador.

Para verificar a versão de produção:

```bash
npm run build
npm start
```
