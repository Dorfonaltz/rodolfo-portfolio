# Rodolfo Vonsoski — Portfólio

Portfólio profissional com foco em back-end, dados e automação, suporte e redes, infraestrutura e cloud.

## Tecnologias

- Next.js
- React
- TypeScript
- React Icons

## Executar localmente

```bash
npm install
npm run dev
```

Depois, acesse `http://localhost:3000`.

## Publicação

O projeto está pronto para publicação automática na Vercel ou Netlify a partir da branch `main`.
